## 📦 3D Assets & Mechanical Hardware

Mekanisme pergerakan *Pan-Tilt* pada proyek ini menggunakan model 3D pihak ketiga yang disesuaikan untuk dudukan kamera/sensor.

* **Nama Desain:** Mini Pan Tilt - Servo G9
* **Desainer Original:** [fbuenonet](https://www.thingiverse.com/fbuenonet)
* **Sumber Aset:** [Thingiverse #708819](https://www.thingiverse.com/thing:708819)

---

### 🛠️ Spesifikasi Komponen & Modul 3D

| Komponen / Aset | Spesifikasi Hardware | Catatan Instalasi |
| :--- | :--- | :--- |
| **Dudukan Pan-Tilt 3D** | FDM Printed STL Files | Dicetak menggunakan filament PLA/PETG. |
| **Aktuator / Actuator** | 2x Micro Servo 9g (SG90 / MG90S) | Memerlukan kalibrasi titik tengah (*center position*) sebelum perakitan mekanis. |
| **Sistem Pengikat** | Tape Perekat ganda / Bumper Mount | Platform kamera belum memiliki lubang baut bawaan; gunakan perekat busa berkualitas tinggi atau adaptor mounting custom. |
